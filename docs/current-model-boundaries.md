# 当前 SGCC 模型使用边界

## 两套模型

| 任务 | 当前制品 | 历史窗口 | 业务输出 |
|---|---|---:|---|
| 资源辨识 | `energy_device_detection/outputs/selected_model.pt` | 120 分钟 | 光伏、能源站、充电桩概率与状态 |
| 光伏功率分离 | `energy_device_detection/pv_outputs/selected_pv_model.pt` | 240 分钟 | 光伏发电功率 kW、活动概率 |

模型输入为总开有功与 A/B/C 三相有功，平台接口单位均为 kW。Runner 内部负责适配 SGCC 现有实现所需单位、特征、归一化和阈值。目标分钟必须是真实点；只允许两端有锚点且不超过 3 分钟的短缺口插值；不读取目标分钟之后的数据。

能源站对应当前 checkpoint 字段 `energy_station_detected`。不得将能源站解释成其他设备类型，也不得生成能源站或充电桩分离功率。无连续窗口、质量不合格或模型不可用时输出为空并附 warnings。

当前充电桩数据没有与总开、光伏、能源站完成真实同步混合验证。当前模型在其他台区正式应用前必须进行外部测试、历史回放、影子比较和人工审批。平台只做监测分析，不提供控制。
