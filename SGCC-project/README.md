# 台区资源辨识与光伏实时分离

本项目基于总开/台区分钟级有功功率数据，训练了两个相互独立的模型：

1. **实时三类资源辨识模型**：每分钟判断当前时刻的光伏、能源站和充电桩运行状态；
2. **光伏实时分离模型**：从总开数据中逐分钟估计光伏实际出力。

两个模型不串联，避免资源辨识错误继续影响光伏功率分离结果。

两套模型的正式输入输出契约见 `energy_device_detection/artifacts/model_contracts.json`。

各文件职责、CSV输入格式、推理命令和完整训练流程见 [`energy_device_detection/README_USAGE.md`](energy_device_detection/README_USAGE.md)。

## 当前交付内容与精度摘要

| 模型 | 当前分钟输入 | 当前分钟输出 | 独立测试结果 |
|---|---|---|---|
| 三类资源实时辨识 | `t-119` 至 `t` 的总开总有功及 A/B/C 三相有功 | `光伏运行状态`、`能源站运行状态`、`充电桩运行状态`及相应概率 | Macro F1 **0.9145**，Macro ROC-AUC **0.9778**，Hamming Accuracy **0.9578** |
| 光伏实时分离 | `t-239` 至 `t` 的总开功率及其因果派生特征 | `分离光伏发电功率(kW)`，即总开中当前分钟的光伏出力 | MAE **0.528 kW**，RMSE **1.504 kW**，R² **0.8962**，测试段累计电量偏差 **-1.16%** |

这里的“实时”指每个分钟数据到达后，对已经到达的当前分钟 `t` 做处理：

- 辨识模型判断三个资源在当前分钟是否有可辨识的运行信号，不是预测未来，也不能在设备完全休眠时证明设备物理上已经安装；
- 分离模型估计当前分钟总开中的光伏功率分量，不输出未来光伏功率，因此不是光伏预测模型；
- 光伏分离不依赖辨识模型的输出，两套模型分别从总开数据独立推理。

辨识的分类指标与光伏分离的回归指标不能直接按同一种“准确率”比较。三类资源分别是光伏、能源站、充电桩；真实充电馈线与同步总开/光伏/能源站数据没有时间重叠，所以充电桩结果不能等同于已经在真实四类混合总开中完成外部验证。

```text
总开最近120分钟 ──► 实时三类资源辨识模型 ──► 当前分钟光伏/能源站/充电桩状态
       │
       └──────► 光伏实时分离模型 ──► 每分钟光伏出力（kW）
```

## 一、实时三类资源辨识模型

### 功能

分钟 `t` 到达后，模型使用 `t-119` 至 `t` 的总开数据，对当前分钟 `t` 进行多标签判断：

- `光伏运行状态`：当前分钟光伏处于运行状态；
- `能源站运行状态`：当前分钟能源站馈线处于高功率运行状态；
- `充电桩运行状态`：当前分钟充电桩处于运行状态。

120分钟只是当前状态辨识的历史上下文，标签不再是“窗口中累计出现过”。模型不读取 `t+1`，也不预测未来。它辨识的是当前运行状态，不是在设备完全休眠时证明其物理上已经安装。

### 输入与输出

- 输入窗口：连续 120 分钟；
- 更新频率：每分钟一次；
- 输入通道：
  - 总有功功率；
  - A 相有功功率；
  - B 相有功功率；
  - C 相有功功率；
- 输出：三个资源的概率和 0/1 标签。

### 最终模型

在相同训练、验证和测试数据上比较了 TCN 与 TCN-LSTM：

| 模型 | 参数量 | 验证集 Macro F1 | 测试集 Macro F1 |
|---|---:|---:|---:|
| 末端因果 TCN | 19,547 | 0.9641 | 0.9029 |
| 末端因果 TCN-LSTM | 27,995 | **0.9700** | **0.9145** |

最终选择验证集表现更好的末端因果 TCN-LSTM。

测试集单类结果：

| 资源 | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|
| 光伏 | 0.8112 | 0.9500 | 0.8751 | 0.9640 |
| 能源站 | 0.8861 | 0.8618 | 0.8738 | 0.9694 |
| 充电桩 | 0.9909 | 0.9985 | 0.9947 | 0.9999 |

非同期标签不再强行写成负样本：同步总开窗口只监督光伏/能源站，充电馈线窗口只监督充电桩，合成窗口监督全部三类。损失、阈值校准和指标都使用同一标签掩码。

单窗口 GPU 前向计算实测约 1.20 ms，不含 CSV 读取和模型首次加载。较晚批次逐分钟端到端核查中，光伏、能源站、充电桩真实状态变化的中位响应延迟均为 0 分钟；光伏在阈值附近波动较多，因此实时状态最不稳定。

## 二、光伏实时分离模型

### 功能

模型从总开历史数据中估计当前分钟的光伏出力：

```text
总开功率 = 光伏功率 + 能源站功率 + 充电桩功率 + 其他负荷功率
```

这是完整的物理组成关系。但当前光伏分离训练批次中只有同步的总开、光伏和能源站表，没有同一时段、同一总开计量边界内的充电桩分表。现有光伏分离模型因此尚未经过充电桩功率干扰的训练和验证。

在线分离时不会使用真实光伏表、能源站表或充电桩表。光伏表只在训练阶段作为监督标签。

这里的任务是**同一时刻的功率分离**：在分钟 `t` 已经到达后，模型使用 `t-239` 至 `t` 的总开数据，估计总开在分钟 `t` 中包含的光伏分量。模型不输出 `t+1` 或更远时刻的功率，不属于光伏功率预测或天气预报任务。

模型内部输出正值形式的分离发电量：

```text
分离光伏发电功率(kW) >= 0
```

同时提供与原始光伏数据符号一致的负功率：

```text
分离光伏有功功率(kW) = -分离光伏发电功率(kW)
```

### 实时约束

- 每次分离只使用当前分钟和之前 239 分钟；
- 不读取未来数据；
- 每收到一个新分钟数据，即可分离该已到达分钟的光伏功率；
- 系统启动后需要先积累 240 分钟历史，或从历史数据库加载缓冲区。

### 输入特征

- 总有功功率；
- A/B/C 三相有功功率；
- 总有功功率一分钟变化量；
- 当前分钟时刻的正弦、余弦编码。

全部电气输入均来自总开表。

### 模型结构

光伏分离使用多任务因果 TCN-LSTM：

1. 因果 TCN 提取光伏爬升、云层波动、下降和三相变化模式；
2. 单向 LSTM 汇总过去 240 分钟的历史状态；
3. 光伏启停头输出当前分钟的发电概率；
4. 功率回归头输出当前分钟的光伏发电功率；
5. 两个输出联合得到总开中当前分钟的连续光伏分量。

### 模型比较

| 模型 | 参数量 | 验证 MAE | 测试 MAE | 测试发电时 MAE |
|---|---:|---:|---:|---:|
| 因果 TCN | 25,610 | 1.078 kW | 1.397 kW | 2.544 kW |
| 因果 TCN-LSTM | 34,058 | **0.644 kW** | **0.528 kW** | **1.293 kW** |

因此光伏连续功率分离最终选择因果 TCN-LSTM。

独立测试结果：

- MAE：0.528 kW；
- RMSE：1.504 kW；
- R²：0.896；
- 光伏发电时 MAE：1.293 kW；
- 不发电时误发电 MAE：0.194 kW；
- 累计电量偏差：-1.16%；
- 光伏启停 Accuracy：0.9472；
- 光伏启停 F1：0.9192；
- 光伏启停 ROC-AUC：0.9921；
- 光伏启停召回率：0.9723。

模型常驻 GPU 时，单个 240 分钟窗口的平均前向计算时间约为 2 ms，不包括程序启动和文件读取时间。

## 三、训练数据

### 光伏、能源站和总开同步数据

第一批：

- `202511050001 光伏`
- `202511050004 总开`
- `202511250005 能源站`

第二批：

- `台区数据光伏0`
- `台区数据总开0`
- `台区数据能源站0`

数据按照 `minute_start` 精确对齐。

### 充电桩数据

- `台区数据12号`
- `台区数据13号`
- `充电桩台区2.1-20251231-20260109-12号`
- `充电桩台区2.2-20251231-20260109-13号`

`充电桩台区1_12.22-12.31_12号` 与 `台区数据12号` 的同期数据基本重复，因此未作为独立监督标签重复使用。

时间核查结果：

| 数据 | 起止时间 |
|---|---|
| 第一批同步总开/光伏/能源站 | 2025-11-25 11:17 至 2025-12-03 14:21 |
| 第二批同步总开/光伏/能源站 | 2025-12-03 15:24 至 2025-12-12 09:34 |
| 较早充电桩馈线 | 2025-12-22 18:12 至 2025-12-31 09:53 |
| 较晚充电桩馈线 | 2025-12-31 10:33 至 2026-01-09 14:45 |

同步总开/光伏/能源站与充电桩馈线的时间重叠为 **0 分钟**，最近两段相隔 10 天 8 小时 38 分。因此：

- 三类资源辨识模型使用了充电桩馈线数据，并通过合成混合样本覆盖三类资源组合；
- 这些组合不是同一时刻、同一总开下的真实同步组合；
- 光伏实时分离模型没有使用充电桩数据，当前指标只代表无同步充电桩标签的两批数据；
- 不能通过平移时间或按行拼接把现有充电桩数据当作光伏分离的同步分量。

### 下采样缺失处理

- 使用每行的 `coverage_ratio` 检查该分钟的原始采样覆盖率；
- 原本缺行、功率无效或覆盖率低于 0.1 的分钟统一视为缺失，阈值可通过 `--min-coverage-ratio` 调整；
- 对两端都有真实分钟且连续不超过 3 分钟的缺口，按时间做双侧线性插值；最大长度可通过 `--max-interpolation-gap-minutes` 调整；
- 没有直接按 `is_complete=1`（0.999）全删，因为现有分片存在规律性的小幅缺采样，这会使 120/240 分钟连续窗口几乎全部消失；覆盖率在 0.1 至 0.999 的分钟仍采用已有样本均值；
- 当前实际参与建模的数据共插值 285 个源分钟：第二批总开/光伏/能源站分别为 1/10/11 分钟，较早两路充电馈线分别为 215/48 分钟，较晚两路为 0；所有缺口都在 3 分钟以内并已填补；
- 插值分钟保留 `is_interpolated` 标记；实时辨识的结束分钟必须有真实总开读数，对应资源分表的当前分钟若为插值值，该标签从监督和评估中屏蔽；
- 光伏回归的目标分钟必须同时具有真实总开和真实光伏读数；插值值只可作为已到达的历史上下文，不能作为回归目标；
- 超过上限、位于数据首尾或缺少双侧锚点的缺口不填，窗口仍不得跨越未填缺口；
- 光伏模型的一分钟功率差分在每个连续片段起点重置为 0，避免把缺口误算成功率突变。

实时 `--latest-only` 模式若最新一分钟本身缺失或质量不合格，会等待下一分钟形成双侧锚点后再输出，不会用前向填充伪造最新值。

## 六、部署建议

实时系统建议按以下方式运行：

1. 常驻加载两个模型；
2. 保存最近 240 分钟总开数据的环形缓冲区；
3. 每分钟到达新数据后更新缓冲区；
4. 调用三类资源辨识模型得到资源标签；
5. 独立调用光伏分离模型得到光伏出力；
6. 将辨识与分离结果和模型版本写入数据库；
7. 定期使用新增的真实光伏表数据检查漂移并重新训练。

不要每分钟重新启动 Python、重新读取所有 CSV 和重新加载模型，否则程序启动和磁盘读取会成为主要延迟。

## 七、限制

- 当前数据主要来自同一个项目和有限日期；
- 尚未覆盖完整季节、天气和不同容量台区；
- 当光伏、能源站、充电桩和其他负荷同时变化时，仅凭总开无法形成数学上唯一的功率分解；
- 光伏分离结果是基于同步数据学习得到的估计值；
- 当前没有与总开/光伏/能源站同步的充电桩分表，不能宣称已验证充电桩干扰下的光伏分离；
- 跨台区部署前应增加其他台区的独立测试；
- 如果实时能源站表和充电桩表可用，建议将其作为额外输入，或采用“总开减能源站减充电桩＋残差模型”提高稳定性。
